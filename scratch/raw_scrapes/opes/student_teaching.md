## Student Teaching Application

### **Watermark Student Learning & Licensure (SL&L)**

Western Kentucky University has transitioned the student teaching application
process to Watermark Student Learning & Licensure (SL&L). Follow the
instructions below to access the portal and submit your application.

[Log In to Watermark
SL&L](https://login.watermarkinsights.com/connect/westernkentuckyuniversity)View
Application Steps

### **Application Deadlines**

Applications are due one year in advance. This lead time is essential for
arranging placements.

**Fall Semester** | October 15th  
---|---  
**Spring Semester** | April 15th  
  
### **Application Instructions**

1\. Sign In to Watermark SL&L

Go to the [WKU Watermark
Portal](https://login.watermarkinsights.com/connect/westernkentuckyuniversity).
Enter your WKU Account username (NetID), click Next, and enter your password
when prompted.

Having login issues? Contact the WKU ITS Service Desk at (270) 745-7000.

2\. Open Program Applications

From the main navigation menu on the left side of the screen, select Program
Applications.

3\. Start an Application

Select the START AN APPLICATION button. If you already have existing
applications on file, click the blue START AN APPLICATION button located in
the top-right corner.

4\. Locate Your Application

Use the search bar or list to locate the student teaching application for your
term (for example, _Application to Student Teach Fall 2027_ under Educator
Preparation Programs) and select it.

5\. Complete Required Fields

Fill in all required fields marked with an asterisk (*) and review your
entered information for accuracy.

6\. Submit or Save as Draft

Select SAVE AS DRAFT if you need to exit and finish later. Once all
information is complete, select SUBMIT.

7\. Confirm Submission

Return to the Program Applications dashboard and verify that your application
status displays as AWAITING REVIEW.
